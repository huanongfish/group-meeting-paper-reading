# 读图方法：怎么把一张图讲透

组会上最见功力的部分就是读图。老师判断学生有没有真读懂论文，通常就看两点：能不能把图里的信息完整读出来，能不能说清这张图在论证里的位置。本文档给出可复用的读图流程与常见图型要点。

## 第一步：判断这张图的论证功能

拿到一张图，先别急着描述内容，先判断它是哪类"论证部件"：

| 功能类型 | 典型位置 | 它在证明什么 |
|---|---|---|
| 立论图（motivation） | 图 1 | 问题存在且重要（现状数据、失败案例） |
| 框架/方法图 | 图 1–2 | 方法怎么运作（流程、结构） |
| 主结果图 | 中部 | 核心主张成立（本文 vs 基线/对照） |
| 消融/分解图 | 中后部 | 增量来自哪个组件 |
| 稳健性/敏感性图 | 后部或附录 | 结论不依赖特定设置 |
| 机制/解释图 | 后部 | 为什么有效（不只是有效） |

功能判断错了，后面的解读会跑偏——比如把机制图当主结果图讲，就会漏掉"作者在回应'为什么'的质疑"这层意思。

## 第二步：逐面板精读

多面板图（Fig. 2A/2B/2C…）必须逐面板讲，顺序上先单个面板、后面板间关系：

**单个面板，按四层读：**
1. **画的是什么**：横轴、纵轴各是什么量（单位、量纲、是否取对数）；颜色/形状/大小映射了什么变量；误差棒/阴影带是标准差、标准误还是置信区间（论文常藏在图注里，要挖出来）。
2. **关键特征在哪**：趋势（单调？拐点在哪？）、组间差异（差多少，差异有没有显著性标记）、离群点（作者提没提？没提的离群点值得在批判环节点出）。
3. **数字落地**：至少读出 1–2 个具体数值（"处理组比对照组高约 40%"），不要只说"明显更高"。
4. **图注核对**：图注里的方法细节（n=多少、什么检验、数据来自哪个时段/站点）与正文方法是否一致。

**面板间关系，判断是哪种组织方式：**
- **递进**：A 提出现象 → B 解释原因 → C 验证推论（讲的时候要把这条链说出来）；
- **对照**：A/B 是不同条件/地区/模型的平行比较（讲清比较维度和结论是否一致）;
- **分解**：A 是总体结果，B/C/D 按子群/组件/尺度拆开（讲清拆分维度，以及拆开后有没有和总体不一致的子结果——不一致处往往是文章的软肋或亮点）。

## 第三步：与方法对应

每张图讲解的第一句话应当能填进这个句式：

> 图 X 是【方法/模型/实验设计 Y】作用在【数据/样本 Z】上得到的【输出类型】。

填不出来，说明方法—结果的对应关系还没理清，回第 5 节（研究方法）补。这一步的意义：组会上被问"这个图的数据是怎么来的"时不至于卡壳，也能发现作者图文不符的地方（比如正文说用了方法 A，图注却是方法 B 的输出）。

## 第四步：故事线定位

用一两句话回答：**去掉这张图，文章的论证会塌在哪里？** 如果答案是"不会塌"，那这张图是锦上添花（可以在讲稿里压缩）；如果是"核心主张就没有直接证据了"，这就是承重图，讲稿里要多分配时间。把全文的图排一排，通常能看出作者的论证骨架：立论 → 方法 → 主证据 → 拆解 → 稳健性 → 机制。解读文档第 6 节的结尾，建议用 3–5 句话把"图表如何串成故事线"整体复述一遍。

## 常见图型的解读要点

- **散点图 + 拟合线**：R²/相关系数多少；拟合是线性还是其它形式、为什么；有没有异方差（点云喇叭口）；离群点是否被特殊处理。
- **箱线图/小提琴图**：比较的是分布不只是均值；注意中位数 vs 均值、箱体重叠程度；n 各是多少（小样本箱线图不可靠）。
- **柱状图 + 误差棒**：误差棒是什么（SD/SE/CI 差别很大）；显著性标记对应什么检验；y 轴是否从 0 开始（截断 y 轴会夸大差异）。
- **时间序列**:趋势、周期、突变点各在哪；有没有做趋势检验（如 MK 检验）；异常时段作者怎么解释。
- **热图**：色标范围是否对称/是否截断；行列排序有没有信息（聚类排序 vs 自然排序）；对角线/分块结构说明什么。
- **地图类**：投影与空间分辨率；高低值的空间格局（沿什么梯度分布）；图例分级是等间距还是分位数（影响视觉印象）。
- **消融表/对比表**：基线选得公不公平（有没有故意选弱基线——可查基线原文报告的数字是否一致）；最好的数字加粗了，但第二名差多少；多个指标之间有没有互相打架。
- **模型结构/流程图**：信息流从哪进从哪出；哪个模块是新的（通常作者会加颜色/虚线框强调）；与已有框架图对比，改动点在哪。

## 表格的读法

表格按"比较逻辑"读：行是什么、列是什么、比较沿哪个方向进行；关键数字是哪个（通常是作者加粗的，但要自己核对是否真是最优）；脚注里的检验方法和数据来源；数字精度是否合理（保留 4 位小数的百分比往往是假精确）。
